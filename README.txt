MK SOLAR ENERGY - ROOFTOP SOLAR WEBSITE

This is a static website for MK Solar Energy, focused on rooftop solar enquiries across Chhattisgarh.

FILES
- index.html                 Main website
- assets/                    MK Solar Energy logo and brand artwork
- google-apps-script/        Google Sheets lead collector
- GOOGLE-SHEETS-SETUP.md     Setup instructions for lead collection

HOSTING
This website can be hosted directly on GitHub Pages because it is a static HTML/CSS/JS site.

GOOGLE SHEETS
Follow GOOGLE-SHEETS-SETUP.md, deploy the Apps Script as a Web App, then paste the Web App URL into index.html.

The form saves leads to Google Sheets and opens WhatsApp for the sales team.
